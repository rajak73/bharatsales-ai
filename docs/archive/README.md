earlier phases of the project (mostly the NestJS + Next.js era, before the move
to Express + React/Vite). They are kept for history only and may describe code
that no longer exists.

API_CONTRACT, BUSINESS_RULES, DEPLOYMENT, RUNBOOK, SECURITY, OFFLINE_SYNC, ERD,
PERMISSION_MATRIX and KNOWN_LIMITATIONS.
